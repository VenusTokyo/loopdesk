# solutions/

Published knowledge-base entries, committed here by LoopDesk itself when a
developer approves an AI-drafted solution in `/admin/`.

This directory starts empty on purpose. Files appear as the loop runs: close
a LoopDesk ticket in the tickets repository, approve the resulting draft, and
the solution lands here as `<subproduct>/<slug>.md`.

Seeded starter solutions live in `backend/seed/seed_solutions.json` instead -
they are loaded into the database, not committed as files.
