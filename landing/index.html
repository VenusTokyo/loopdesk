The fix stops dying in the closed ticket.

Step through what happens after a developer closes an issue.

Three things it does on purpose.

It refuses to guess

Citations to ids that were never offered are dropped. With nothing left, confidence is capped below the gate and you get a ticket — never an invented step.

# agent/schema.py
if sol_id not in allowed_ids:
  continue
if not matches:
  confidence = min(confidence, 0.2)

Private data never enters the image

Fields marked private are masked before the pixels are rendered. On blocklisted routes the capture code never loads at all.

> window.LoopDesk
undefined // on /settings/payment

The knowledge base grows itself

Close an issue and a solution that did not exist ninety seconds ago is listed for the next user on that page.
